# 強さ偏差値: 登録レートを事前分布に＋スコア差を軽く反映

2026-10-05

## 背景 / 要望

履歴画面の強さ偏差値（`src/lib/performanceRating.ts`、正則化付き Bradley-Terry。
詳細は [2026-07-27-performance-rating.md](2026-07-27-performance-rating.md)）は、
全員を θ=0 からスタートし、その日の勝敗だけで推定している。1日 5〜8 試合では
「相手が弱い／味方が強い」こと自体が分からないため、**強い味方のおかげで弱い相手に
勝った人も、本人の手柄として偏差値が上がってしまう**。

## 決定事項（ユーザー確認済み）

| 項目 | 決定 |
| --- | --- |
| 初期値（事前の実力） | 重視する。アプリ内の登録レート `Player.rating` を事前分布の中心に使う |
| スコア差 | 軽く反映する（勝敗 70% + 得点率 30%） |
| 開発モードの編集画面 | 参加者編集に読み取り専用で初期レートを表示 |

## 変更内容

### 1. 登録レート → 事前平均 μ_i（`performanceRating.ts`）
- 登録レートの尺度はセッションごとに不定（30〜40 も 1500 もある）ため、
  **その日の参加者のうち `rating > 0` の人で z 化**する。`μ_i = PRIOR_SPREAD · z`。
- 未レート（未設定 or 0。`ratingSummary.ts` と同じ解釈）は `μ = 0`。レート登録者が
  2人未満、または `sd≈0` なら全員 `μ = 0`（＝従来と同じ挙動）。
- 正則化の強さは人ごと。レートあり `λ = 1.0`、なし `λ = 0.5`（従来値）。
  更新式は `g = grad − λ_i(θ_i − μ_i)`、`h = curv + λ_i`。
  LOO（`matchInsights`）の解き直しにも同じ priors を渡し、その推定に現れない選手は
  事前平均で代用する。
- 登録レートは名前ベースで引く。同名が複数いる場合は後ろの人が優先
  （既存の同順位時の登録レート比較と同じ扱い）。
- `estimateStrengthsById`（自動配置の補正）は従来どおり勝敗のみ・登録レートなし。

### 2. スコア差を軽く反映
- `RatedMatch.outcomeA = (1 − SCORE_WEIGHT)·winA + SCORE_WEIGHT·scoreA/(scoreA+scoreB)`。
  例: 21-19 勝ち → 0.86、21-5 勝ち → 0.95。
- `scoreA + scoreB <= 0`（未入力）は `outcomeA = winA`（従来どおり）。
- 推定の残差（`outcomeA − predicted`）にだけ使う。勝敗数・勝率・期待勝利数・
  `judgeMatch` は勝敗ベースのまま。

### 3. 付随修正
- 期待勝利数の「平均的な選手」は θ=0 ではなく **θ の全体平均**に置き換える
  （事前平均の導入で中心が 0 から動くため）。
- 偏差値・男女別偏差値の正規化（平均 50 / SD 10）は変更なし。

### 4. 開発モードで参加者編集に初期レートを表示
- `PlayerEditModal` に `playerRating?` / `showRating?` を追加。`showRating` のとき名前欄の下に
  「初期レート: 1500」（未設定・0 は「未設定」）を読み取り専用で出す。保存処理は変更なし
  （編集は従来どおり名前欄の「名前 レート」記法）。
- `PlayerSelect` で `useDevMode()` を使い `showRating={devMode}` を渡す。

## 定数の根拠

| 定数 | 値 | 根拠 |
| --- | --- | --- |
| `PRIOR_SPREAD` | 0.6 | θ 単位。≒ 104 レート差（1SD の登録レート差で勝率 約65%）。1日分の推定誤差（±5.5 偏差値）より強く出し過ぎない控えめな値 |
| `RATED_PRIOR_STRENGTH` | 1.0 | 約4試合分の勝敗情報に相当。1日 5〜8 試合では事前が残り、試合が増えれば結果が上回る |
| `PRIOR_STRENGTH`（レート無し） | 0.5 | 従来値 |
| `SCORE_WEIGHT` | 0.3 | 僅差と圧勝を軽く区別しつつ、勝ちは常に 0.5 超で勝敗を覆さない |

## テスト
- 高レートの味方と組み低レートの相手に勝った人の偏差値が、レート情報なしより低い
- 少数試合はレート順に寄る／全員同レート・レート登録者1人以下は従来と同結果
- 21-5 勝ちは 21-19 勝ちより高い／スコア 0-0 は勝敗のみと同じ
- 試合順非依存・mean≈50 / sd≈10・LOO・80試合性能
- `PlayerEditModal` の初期レート表示/非表示
