# 2026-05-19 短時間試合の警告マーク表示

## 背景・課題

試合履歴に時々「数秒〜十数秒で終わっている試合」が混ざる。
これはコート操作画面で **試合終了ボタンを誤タップ** したか、
試合開始直後に **誤って終了→新規開始** を踏んだ結果で、
本来削除すべきレコードが残ってしまっているケースが多い。

実力差があっても 3 分未満で 1 ゲームが終わることは現実的に無いので、
`finishedAt - startedAt < 180s` の試合は操作ミスの可能性が高いと判断し、
履歴画面で視覚的に警告したい。

## 方針

`src/pages/HistoryPage.tsx` の `MatchCard` に、
**時間と点数を表示している行の直下** へ 1 行追加する:

```
⚠️ 試合時間が短すぎます（操作ミスの可能性）
```

- 条件: `(match.finishedAt - match.startedAt) / 1000 < 180`
- 入力済み / 未入力 どちらでも表示する
  （未入力かつ短時間は「ボタン誤タップで即終了 → スコアも入っていない」
  という最も典型的な誤操作パターンで、むしろ目立たせたい）
- スタイル: 既存の警告色 (orange / yellow 系) を流用。
  `Toast.tsx` で使用済みの `AlertTriangle` アイコン（lucide-react）を使う。
  バッジっぽくせず、説明文として行で出す。

## 影響範囲

- 表示専用。データモデル・Firestore 書き込みには手を入れない。
- CSV / Sheets エクスポートには影響しない（時間は既に分単位で出ている）。
- 編集/削除ボタンの導線はそのまま。警告に気づいたユーザは
  既存の編集・削除フローで対処できる。

## テスト

- 単体ロジックの境界値テスト（179s → 警告あり、180s → 警告なし、
  300s → 警告なし）を `MatchCard` 単位で確認できると望ましいが、
  既存ページに対するコンポーネントテストは無いので、
  最小限のユニットテストを追加するか手動確認のみとするかは実装時に判断。
- 手動: 履歴画面で短時間試合のレコードを 1 件作って表示確認。
