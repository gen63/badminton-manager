# 2026-05-19 短時間試合の警告マーク表示

## 背景・課題

試合履歴に時々「数秒〜十数秒で終わっている試合」が混ざる。
これはコート操作画面で **試合終了ボタンを誤タップ** したか、
試合開始直後に **誤って終了→新規開始** を踏んだ結果で、
本来削除すべきレコードが残ってしまっているケースが多い。

実力差があっても 2 分台で 1 ゲームが終わることは現実的に無いので、
`finishedAt - startedAt <= 150s` の試合は操作ミスの可能性が高いと判断し、
履歴画面で視覚的に警告したい。

## 方針

`src/pages/HistoryPage.tsx` の `MatchCard` で、**連番バッジの真上**に
小さな ⚠️ アイコンだけを差し込む。説明文は `title` 属性 /
`aria-label` で持たせ、**ホバー時 (PC) のツールチップ・
スクリーンリーダーでのみ読み上げ**で表示する。常時表示の文は持たない
（リストが視覚的に煩雑になるため）。

スマホでは `title` がほぼ表示されないため、アイコンは `<button>` で
描画し、タップで `useToast().warning()` 経由のトーストを下から出して
同じ文言を見せる。これでマウスホバー (PC) / タップ (モバイル) /
スクリーンリーダーの 3 つで同じ情報にアクセスできる。

- 条件: `match.finishedAt - match.startedAt <= 150_000`
- 入力済み / 未入力 どちらでも表示する
  （未入力かつ短時間は「ボタン誤タップで即終了 → スコアも入っていない」
  という最も典型的な誤操作パターンで、むしろ目立たせたい）
- アイコン: `AlertTriangle` (lucide-react)、`text-amber-600`、`cursor-help`。
- 配置: 連番バッジを `flex flex-col` でラップし、ON のときだけ
  アイコンが連番の上に乗る。OFF のときは連番だけが残り、列の
  垂直中央がカード行の垂直中央に揃う。
- ツールチップ文言: 「試合時間が短すぎます（操作ミスの可能性）」

## 影響範囲

- 表示専用。データモデル・Firestore 書き込みには手を入れない。
- CSV / Sheets エクスポートには影響しない（時間は既に分単位で出ている）。
- 編集/削除ボタンの導線はそのまま。警告に気づいたユーザは
  既存の編集・削除フローで対処できる。

## テスト

- 単体ロジックの境界値テスト（149s → 警告あり、150s → 警告あり、
  151s → 警告なし）を `MatchCard` 単位で確認できると望ましいが、
  既存ページに対するコンポーネントテストは無いので、
  最小限のユニットテストを追加するか手動確認のみとするかは実装時に判断。
- 手動: 履歴画面で短時間試合のレコードを 1 件作って表示確認。
