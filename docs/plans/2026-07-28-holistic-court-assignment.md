# 3コート以上の逐次貪欲配置の解消と、2コート経路との統合

2026-07-28

## 課題

`assignCourts` にはコート数によって別系統のロジックが2つあった。

- **2コート同時配置**（`assign2CourtsHolistic`）: 8人をまとめて選出 → 2コートへ振り分け →
  `tryFixRecentMatch` で直近重複を修復
- **3コート以上**: `for` ループで**1コートずつ** `selectMostUrgentGroup` →
  `selectBestFour` → `usedPlayers` に追加、を繰り返す

問題は2点。

1. **3コート以上が逐次貪欲**。各コートが制約（直近試合の重複・性別構成）を満たすために
   隣接グループから候補を**事前に借用**していたため、先に処理されたコートが後のコートの
   候補まで先取りし、最後のコートが残り物になっていた
2. **ロジックの二重化**。性別のまとめ配置は2コート経路にしか無いなど、片方だけ実装
   された機能が既にあり、片方だけ直す事故が起きやすかった

## 変更

### 1. 事前借用をやめ、後始末で解消する

- 各コートの候補は**自分のレーティング帯のメンバーだけ**に限定する。他コートが確定する
  前に候補を先取りしない
- 自グループの残りが4人に満たない場合のみ、不足分＋`RESCUE_CANDIDATE_BUFFER(8)` を
  他グループから補充する（`groups3` は常に3グループ固定なので、4コート以上では
  同じラウンドで同一グループが2回選ばれ、構造的に枯渇しうるため）
- ラウンドの全コート選出後に **`repairCourtConstraints`** で横断的に後始末する。
  直近試合の重複・上下孤立・性別ハード制約の違反が残っていれば、他コートとの1人
  スワップで解消する。**実力差（`getSkillGapPenalty`）が悪化するスワップは採らない**

### 2. 2コート経路との統合

`assign2CourtsHolistic` の `tryFixRecentMatch` を廃止し、`repairCourtConstraints` に
統合した。2コートからは `groups3` などを渡さずに呼び、直近試合の重複解消だけを行う
（旧 `tryFixRecentMatch` と同じ振る舞い）。

実装上の非対称が1点ある。**実力差ガードは3コート以上でのみ効かせている**。2コートの
修復は元々このガードを持たず、追加すると「修復できたはずのスワップが見送られ、別の
スワップ（性別バランスを崩すもの）に流れる」形で 2コートの性別バランスに副作用が
出たため（実測で確認）。3コート以上は選出時にも `getSkillGapPenalty` を使っており
整合する。

## 効果（自分で再計測。focus/bench は 80/40シード、gbench は 100シード）

| 指標 | 変更前 | 変更後 |
| --- | --- | --- |
| **18人3コート 試合数の幅** | 2.0 | **1.1** |
| **21人3コート 試合数の幅** | 1.9 | **1.4** |
| 18人3コート 上位3×下位3 | 4.6% | **3.1%** |
| 21人3コート 上位3×下位3 | 2.1% | **1.2%** |
| 18人3コート 序列差 | 8.03 | **7.31** |
| 21人3コート 序列差 | 8.56 | **7.75** |
| 18人3コート 回転（使ったコート数） | 2.96/3 | 2.96/3（維持） |
| 21人3コート 回転 | 2.90/3 | 2.92/3 |
| 実力が近い相手との未共演率 | 31% | **28%** |
| 18人少数派2 3-1 / 2-2 | 24.0% / 9.3% | **10.9% / 16.0%** |
| 18人少数派3 3-1 / 2-2 | 23.7% / 20.6% | **13.6% / 25.8%** |

逐次貪欲の解消が、**試合数の公平性・実力分離・3-1 の削減に同時に効いた**。事前借用が
「制約を満たすために実力帯をまたいで候補を引っ張る」動作だったため、それをやめて
後始末に回した結果、実力帯の分離も自然に強まっている。

## 悪化した点（正直な記録）

1. **処理時間**: 20人4コート60試合の合計で 25ms → 60〜68ms（約2.5倍）。ただし
   **1回の配置あたりの定常コストは 1.9ms → 2.4ms**、初回のみ 4ms → 12〜15ms。
   実運用では1試合ごとに人が操作するため体感差は無い
2. **18人・少数派3人の試合数差**: 0.18 → 0.28。300シードでも再現するのでノイズでは
   ない。3-1 の試合が大きく減った副作用で、少数派が 3-1 で出場していた分が減ったため
   （少数派2人は 0.48 → 0.40 と改善、少数派6人は 0.22 → 0.16 と改善）
3. **少数派6/9人の 3-1 がわずかに増**（5.1% → 6.0%、3.2% → 3.6%）
4. **実力が離れた相手との未共演率が 72% → 81%**。実力分離が強まった裏返しで、
   「人数が多いときに実力差がある人と当たらないのは意図どおり」という方針に沿う

## テスト

既存 580 件が**1件も変更なしで通過**した。予約（reservation）まわりを含め、配置順序に
依存したテストの破壊は無い。

## 非対象

- `assign2CourtsHolistic` の `Math.random()`（再現性が無く、2コートの計測はシード間で
  ぶれる）。決定的な乱数への置き換えは別途
