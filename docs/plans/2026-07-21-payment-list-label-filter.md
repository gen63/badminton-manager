# 支払い一覧の改善（ラベル修正・金額フィルタ・連番）

対象: `src/pages/AccountingPage.tsx`（支払い一覧タブのみ）。計算ロジック
（`src/lib/accountingCalc.ts`）・Firestore 同期には手を触れない。

## 背景・課題

支払い一覧タブのサマリーとリストは `paymentStats`（`AccountingPage.tsx` の
`useMemo`）で `players.filter(p => p.operationStatus?.payment)` を集計している。
`operationStatus.payment` は「**会計操作を対応済み**」を表すフラグであり、
**免除（`paymentAmount === 0`）メンバーも `payment === true`** になる。

その結果:
- サマリーの「**支払い済み 10/10人**」は実際には「会計対応済み」の人数で、
  送金していない免除メンバーも含むため、日本語ラベルが実態とズレている。
- 「合計金額 ¥3,000」は `paymentAmount` の合計なので免除は加算されず正しい。

## 変更内容

### 1. サマリーのラベル修正
- 「支払い済み」→「**会計対応済み**」に文言変更。
- 「合計金額」の下（または「うち免除」の近く）に「**送金済み ○人**」行を追加。
  `送金済み = 会計対応済み人数 − 免除人数`（= `paymentAmount > 0` の人数）。
- 既存の「うち免除 ○人」行は据え置き。

### 2. 金額での絞り込みフィルタ（動的チップ）
- 「支払い詳細」見出しの下にフィルタチップ行を追加。
- チップは `paymentStats.players` に実在する金額から動的生成:
  - 「全て」（デフォルト選択）
  - 「免除」（`amount === 0` が1人以上いる場合のみ）
  - 実在する非0金額を昇順で `¥500` `¥600` … のように列挙。
- 選択状態は `useState<'all' | number>`（`0` を免除に割当てず、免除は別センチネル
  または `amount === 0` で判定）。選択に応じてリストを `filter`。
- チップのスタイルは既存の `select-button` / `select-button-active` /
  `select-button-inactive` を流用し、デザインの一貫性を保つ。
- フィルタは表示のみに作用。サマリーの集計値（対応済み/送金済み/合計/免除）は
  常に全体を表示し、フィルタで変動させない。

### 3. 支払い詳細に連番付与
- リスト各行の左に連番（1, 2, 3…）を表示。
- 連番はフィルタ適用後の表示リストに対して振る（表示順で 1 から連番）。

## 非対象
- `operationStatus.payment` のデータ構造やフラグ名は変更しない（互換性維持）。
- コピー用テキスト・アップロード・入力タブには影響を与えない。

## 確認
- `npm run build` / `npm run lint` / `npm run test:run` を通す。
- 免除のみ・送金のみ・混在の各パターンで表示崩れがないこと。
