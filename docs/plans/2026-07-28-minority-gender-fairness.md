# 少数派性別が1人のときの試合数不利を解消する

2026-07-28

## 背景 / 症状

「男8・女1のとき、女性の試合数が極端に少なくなる」という報告。実測（16ラウンド、
本番と同じ滞在時間ベース優先度）で再現した。

| 構成 | 多数派の平均試合数 | 少数派の試合数 | 差 |
| --- | --- | --- | --- |
| 男8 女1 / 2コート | 14.5 | 12 | **−2.5試合** |
| 男8 女1 / 1コート | 7.4 | 5 | **−2.4試合（32%減）** |
| 男13 女1 / 3コート | 13.8 | 12 | −1.8試合 |
| 男12 女2 / 3コート | 13.8 | 13 | −0.8試合 |
| 男11 女3 / 3コート | 13.7 | 13.7 | ±0 |
| 男10 女4 / 3コート | 13.7 | 13.8 | ±0 |

**少数派が1人のときだけ明確に不利**で、3人以上ではほぼ解消する。

## 原因（2箇所）

いずれも「2-2 構成を作れない状況でも 3-1 回避が効き続ける」ことが本質。

1. **`getGenderPenalty` の 3-1 ペナルティ**（`oneGameDelta * 3.0` = 3試合分）
   女性が1人なら彼女を含む組は**必ず 3-1**。常にこのペナルティを背負うため、
   「3試合分出遅れるまで選ばれない」状態が維持される。
2. **`assign2CourtsHolistic` の「少数派が奇数なら1人外す」処理**
   ガードが `replacePriority - excludePriority < oneGameDelta * 2` なので、
   その人が2試合分遅れるまで外され続ける。少数派1人なら常に奇数で毎回該当する。

既存の `shouldAllowUnbalancedGender()`（少数派が30%未満なら 3-1 を許容）は
**ハード制約 `hasUnbalancedGender` にしか効いておらず**、上記2つには届いていなかった。

## 設計

### 判定を `shouldAllowUnbalancedGender` で代用しない

当初は `shouldAllowUnbalancedGender`（30%未満）をそのまま流用する案だったが、
実測すると**副作用が大きい**。この判定は男11女3（21%）や男10女4（28.6%）も true に
なるため、それらの構成でも 3-1 ペナルティが消えて 3-1 の試合が増えてしまう
（男11女3 で 3-1 比率 39.6% → 54.2%）。

### `isGenderPairImpossible`（新規）

**少数派がちょうど1人＝どう組んでも 2-2 が物理的に作れない場合のみ** true を返す、
より狭い判定を追加する。少数派が2人以上なら 2-2 を作れる余地があるので、従来どおり
ペナルティで 2-2 / 4-0 へ誘導する。

- `getGenderPenalty(combo, oneGameDelta, genderPairImpossible)`:
  true のとき 3-1 ペナルティを 0 にする。MIX(2-2) の 0.5 は変更しない
- `assign2CourtsHolistic`: true のとき「少数派が奇数なら外す」処理をスキップ
- `assignCourts` でセッション全体（`options.allPlayers`）から一度だけ算出し、
  `selectBestFour` の全呼び出しと `assign2CourtsHolistic` へ渡す
- ハード制約側（`shouldAllowUnbalancedGender` → `allowUnbalanced`）は**変更しない**

## 効果

| 構成 | 修正前の差 | 修正後の差 |
| --- | --- | --- |
| 男8 女1 / 2コート | −2.5試合 | **−0.3試合** |
| 男8 女1 / 1コート | −2.4試合 | **−0.1試合** |
| 男13 女1 / 3コート | −1.8試合 | **+0.3試合** |
| 男12 女2 / 3コート | −0.8試合 | −0.8試合（判定に入らず不変） |
| 男11 女3 / 3コート | ±0 | ±0（同上） |
| 男10 女4 / 3コート | ±0 | ±0（同上） |
| 男7 女7 / 3コート | −0.3試合 | −0.3試合（同上） |

少数派2人以上の構成は `genderPairImpossible` が false のままなので、コードパス自体に
入らず**完全に同一の結果**になる。3-1 の発生比率も変化なし（男11女3 で 39.6% のまま）。

実力差の分離（`2026-07-28-skill-gap-separation.md`）にも影響しないことを確認済み
（18人3コートで上位3×下位3 = 4.3%、序列差 7.96 と変更前後で一致）。

## テスト

`src/lib/algorithm.test.ts`

- 少数派が1人のセッションでは 3-1 ペナルティが効かず、最も待っている女性が配置される
- セッション全体（`options.allPlayers`）で少数派が2人以上なら、その回の候補に女性が
  1人しかいなくても従来どおり 3-1 を避ける
- 既存の `lateBalanceMode` テスト2件は 4M+1F（少数派1人）で偶然この新分岐に入って
  しまうため、試合数 100 の女性を1人足して少数派2人に補正した。追加した人は優先度が
  著しく低く選ばれないため、テストの本来の意図（`LATE_BALANCE_WEIGHT` と性別ペナルティ
  の境界）は変わらない

## 非対象

- 少数派が2人のとき残る −0.8試合の差。2-2 が作れる構成なので現状の設計どおりだが、
  気になるようなら別途調整する
- 3-1 を避ける方針自体の是非（現行方針を維持している）
