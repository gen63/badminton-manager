# ダブルスのチーム分けを「最強＋最弱 vs 2位＋3位」に固定

## 背景
- 2026-10-03 の実データ（59試合）で、レート下位のメンバーが12試合中11試合で登録上の不利側に入り、最強＋最弱にならない分割が複数あった。
- 原因の一つは、男女バランス点（男男 vs 女女 30点 / OFF 時 14点、3-1 は 40 / 12点）がチーム差の点（teamDiff 3点/偏差1）に勝ち、最強＋最弱の分割が選ばれない試合があったこと。
- 分析で分かったこと:
  - 当日勝敗補正（kRated 有限）は効果が有意でない（1日分では判断不能）。kRated=∞ を維持。
  - 期待勝率の不足（deficit）を点数に足す案は、λ=80 で下位の期待勝率 +3〜4pt、λ=320 で +9pt だが、外れ値日に副作用がある。今回は見送り（別 plan 候補）。
- 未解明事項: 当日の実データの分割のうち #7, #37, #46, #57 など数試合は、現行の採点（男女比 OFF・登録レートどおり）でも再現できなかった（予約2試合・手動1試合は除外済み）。原因候補（推測）は端末が古いビルド（PWA キャッシュ等）で動いていた等。本変更で分割は決定的になる。

## 決定（ユーザー）
4人が決まった後のチーム分けは、偏差順 a≥b≥c≥d で **[a+d / b+c] に固定**する。
a≥b≥c≥d のとき |(a+d)−(b+c)| ≤ (a+c)−(b+d) ≤ (a+b)−(c+d) なので、a+d / b+c は常にチーム平均差が最小。男男 vs 女女になってもよい。パートナーの繰り返しは気にしない（現行エンジンに該当項は無い）。

- 例外: ペア希望「必ず」(strongPairs) が a+d / b+c で違反になるときのみ、従来どおり3分割から（違反, 点数）最小を選ぶ。
- 通常（弱い）ペア希望の pairEnemy は分割を変えない。ただしコート点数には従来どおり加算し、顔ぶれ選択に効かせる。
- 男女点（gender）も分割の選択には使わないが、固定分割の点数としてコート点数に加算し続ける（顔ぶれ選択では男女バランスが引き続き効く）。
- 対象外: 予約（4人予約は「最初の2人 vs 残り2人」固定）、旧エンジン（useObjectiveEngine:false）。

## 変更
- `src/lib/pairing/assignRound.ts` の `evalCourt`: a+d / b+c が「必ず」違反なしならそれを採用（break）。違反ありのときだけ残り2分割と比較。タイブレークは従来どおり（偏差降順、同値は id 昇順）。
- テスト: `assignRound.test.ts` に (a) 男男 vs 女女でも最強＋最弱、(b) 「必ず」違反時のフォールバック を追加。分割の期待値が変わる既存テストは要件どおりに更新。
