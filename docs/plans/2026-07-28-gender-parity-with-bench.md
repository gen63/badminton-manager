# 3コートで人数が少ないときの 3-1 増加を抑える（待機者との入れ替え）

2026-07-28

## 背景

`2026-07-28-holistic-court-assignment.md`（各コートが自分の実力帯から選出するように
した変更）で実力分離は大幅に良くなったが、**男女半々・3コート・13〜16人のときに
3-1 構成の試合が明確に増えた**。

| 人数 | 3-1 の割合（改善前 → 統合後） | 上位3×下位3 |
| --- | --- | --- |
| 13人 | 11.1% → 27.6% | 40.9% → 18.4% |
| 14人 | 2.3% → 22.6% | 35.7% → 12.9% |
| 15人 | 1.1% → 13.2% | 32.1% → 12.8% |
| 16人 | 0.7% → 13.4% | 27.7% → 7.3% |
| 18人 | 3.2% → 3.9%（問題なし） | 21.3% → 5.0% |

## 原因（当初の仮説とは違った）

当初は「`repairCourtConstraints` の実力差ガードが性別修復を阻んでいる」と考えたが、
計測すると**それだけでは説明できなかった**。ガードを無制限に緩めても、13人のケースで
救えるのは性別違反 162 件中 22 件だけだった。

本当の原因は**パリティ（偶奇）**である。

- コート間でメンバーを入れ替えても、**出場している 12 人の中の少数派の総数は変わらない**
- 各コートの少数派人数の合計＝その総数。全コートが 2-2 か 4-0（＝偶数）なら合計は偶数
- したがって**出場者の中の少数派が奇数なら、どう入れ替えても 3-1 のコートが必ず 1 つ以上
  残る**

3コートは 12 人が出場するので、13〜16人だと待機は 1〜4 人。誰が休むかによって出場者の
少数派人数の偶奇が決まり、奇数になった回は 3-1 が不可避になる。18人（待機6人）では
選出の自由度が高く、自然に偶数側に落ち着くため問題が出ない。

## 変更

### 1. 性別違反の修復に限り実力差ガードを緩める（`GENDER_GAP_ALLOWANCE`）

`repairCourtConstraints` のコート間スワップで、**純粋な性別違反を直す入れ替えのみ**
実力差の悪化を一定幅まで許容する。直近試合の重複・上下孤立の修復は従来どおり厳格。

幅は 0 / 0.5 / 1 / 1.5 / 2 / 3 / 4 / 8 を比較し、2.0（＝`SKILL_GAP_WEIGHT` と同値）で
効果が頭打ちになったのでそこを採用。

### 2. 待機者との入れ替え（`repairGenderParityWithBench`）

パリティを変えられるのは「誰が出るか」を変えたときだけなので、`repairCourtConstraints`
の後に、まだ性別違反が残るコートについて**待機者と入れ替える**処理を追加する。

ガード:

- **待機が2人以上のときのみ実行**。1人しか待機がいない構成（13人3コート等）では入れ替えが
  一方向にしか成立せず、試験的に実行させたところ試合数差が −1.78 まで悪化したため見送る
- **待機側の試合数が、外れる人より多い場合は入れ替えない**
  （`GENDER_PARITY_BALANCE_TOLERANCE = 0`。−1.5〜2 を振って、公平性がベースラインの
  ぶれの範囲に収まる 0 を採用）
- 直近試合の重複・上下孤立のチェックは従来どおり
- 少数派が少ないセッション（`preferGenderMix`）と 3-1 許容セッション（`allowUnbalanced`）
  では実行しない（前者は `repairLoneMinorityPairs` が担当）

なお「出場者を選ぶ段階でパリティを見て、あらかじめ休ませる人を決める」案も試したが、
実際の選出を読み違えて無関係なコートまで悪化させた（15人で上位3×下位3 が 12.8% → 16.1%）
ため不採用。**選出後に、実際に違反が残ったコートだけ直す**形にしている。

## 効果（60シード平均、男女半々）

| 条件 | 3-1（前 → 後） | 上位3×下位3 | 試合数差 |
| --- | --- | --- | --- |
| 13人3コート | 27.6% → 27.1% | 18.4% → 18.8% | −0.10 → −0.12 |
| 14人3コート | 22.6% → **16.9%** | 12.9% → 13.8% | −0.05 → 0.01 |
| 15人3コート | 13.2% → **10.4%** | 12.8% → 12.7% | −0.01 → 0.02 |
| 16人3コート | 13.4% → **9.1%** | 7.3% → 8.3% | −0.03 → −0.06 |
| 18人3コート | 3.9% → **2.6%** | 5.0% → 5.2% | 0.01 → −0.02 |
| 14人2コート | 18.3%（完全一致） | 33.4%（完全一致） | −0.09 |
| 12人2コート | 20.5%（完全一致） | 39.0%（完全一致） | 0.08 |

- 性別なしのセッション（`focus.ts` / `reach.ts`）は**完全一致**
- 2コート経路は**完全一致**（待機者入れ替えは3コート以上の経路のみ）
- `gbench_after.ts` の少数派が少ない条件も無変化、対象外の 18人少数派6/9 は改善

## 未達成（正直な記録）

目標は「14人で 3-1 を 10% 以下、13人で 15% 以下」だったが**未達**。

- **13人3コートはほぼ改善しない**（27.6% → 27.1%）。待機が1人だけの構成では、公平性を
  守る限り入れ替えがほぼ成立しない。解消するには**誰を休ませるかの選出そのもの**に
  パリティを持ち込む必要があり、公平性への影響が大きいため今回は見送った
- 14/15/16人は目標未達だが大幅改善（22.6% → 16.9%、13.2% → 10.4%、13.4% → 9.1%）

さらに下げたい場合は、選出段階で「出場者の少数派人数が偶数になるように休む人を選ぶ」
必要がある。試合数の公平性とのトレードオフになる。

## テスト

- 待機者との入れ替えで 3-1 が解消されること
- 待機が1人以下のときは実行されないこと
- 待機側の試合数が多い場合は入れ替えを拒否すること
