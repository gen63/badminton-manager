# セッション一覧に試合数の中央値を表示（開発モード限定）

## 背景 / 目的

セッション選択画面のカードには総試合数（`32試合`）は出ているが、「1人あたり
どれくらい試合をこなしたか」が分からない。総試合数は参加人数とコート数に強く
引きずられるため、セッション間の比較には使えない。

1人あたりの試合数の**中央値**を出すと、

- セッション単位の「濃さ」を人数によらず比較できる
- 予約保留の閾値（`reservationBlockThreshold` = 中央値 + N）のチューニング時に、
  実セッションの中央値がどのあたりに出るかを一覧で確認できる

開発モード限定の運用者向け情報なので、一般参加者の画面は変えない。

## 表示仕様

### 母集団

**`gamesPlayed > 0` のプレイヤーのみ**。

名簿登録だけして参加しなかった人・見学者・途中離脱で1試合もしなかった人を
母集団に含めると中央値が下振れし、「実際にプレイした人の体感試合数」から
ずれるため。

配置アルゴリズム側の中央値（`algorithm.ts` の予約保留判定）は在席全員（休憩者
込み・0試合含む）を母集団にしており、**定義が異なる**。これは意図的で、
アルゴリズム側は「割り込みを止める基準」、一覧側は「セッションの実績サマリ」
という別目的のため。両者を統一しないこと。

母集団が0人（＝誰も試合していない）のときは `undefined` とし、非表示。

### 数値の書式

- 偶数人のときは中間2値の平均になるため `4.5` のような .5 が出る
- 整数なら小数点なし（`4`）、端数があれば小数点1桁（`4.5`）

### 配置

`SessionSelectPage` のカード2行目（周知事項メモの行）の**先頭**に置く。

```
[複] 8/13(木) 14名 千川館 32試合 💵10,200      ← 1行目（変更なし）
中央 4.5  📄 入りやすい人が表示される配置予測…   ← 2行目（先頭に追加）
```

1行目は `flex-nowrap` + `flex-shrink-0` で既に横幅が限界（体育館名が truncate
され始めている）ため、1行目には足さない。2行目のメモは `flex-1 + truncate`
なので、先頭にチップを差し込むだけでメモ側は自動的に短くなる。メモの右寄せ
指定などは不要。

- チップは `tabular-nums` + 固定 `min-w`（`3.75rem` 目安）にして、全カードで
  メモの開始 x 座標を揃える。バラつくとリストとして読みにくい
- スタイルは既存メタ情報と同じ `text-xs text-muted-foreground`
- ラベルは「中央」。総試合数（`32試合`）と誤読されないよう、Trophy アイコンは
  使わない

### 行の描画条件

現状の2行目は**メモがあるときだけ**描画されている
（`session.information?.text?.trim()` で分岐）。中央値はメモの有無と独立して
出したいので、**「開発モードで中央値がある」または「メモがある」**のいずれか
で行を描画するよう条件を組み替える。

## 実装方針

### 1. `src/lib/median.ts`（新規）

```ts
/** 数値配列の中央値。空配列は 0。偶数個は中間2値の平均 */
export function median(values: number[]): number

/** gamesPlayed > 0 のプレイヤーの試合数中央値。該当0人なら undefined */
export function medianGamesPlayed(players: Player[]): number | undefined
```

`median()` の実体は `algorithm.ts:1899` と `algorithm.ts:2012` に既に同じものが
2箇所ベタ書きされている。3箇所目を作らないよう、この2箇所も `median()` 呼び出しに
差し替える（**母集団の作り方は各所そのまま**、ソート＋中央値取得のみ共通化する
純粋な抽出リファクタ。挙動は変えない）。

### 2. `src/types/session.ts`

`Session` に `medianGamesPlayed?: number` を追加（`matchCount` / `paidCount` /
`incomeTotal` と同じ派生フィールド群の並び）。

### 3. `src/services/sessionService.ts`

`docToSession` 内で `medianGamesPlayed(gameState?.players ?? [])` を呼んで詰める。
`gameState.players` は同一ドキュメント内に既にあるので**追加読み込みは発生しない**。

### 4. `src/pages/SessionSelectPage.tsx`

上記「配置」「行の描画条件」の通り2行目を組み替える。`devMode` 限定。

## テスト

`src/lib/median.test.ts` を新規追加:

- 奇数個 / 偶数個（.5 が出る）/ 1人 / 空配列
- `medianGamesPlayed`: `gamesPlayed === 0` の人が除外されること、全員0なら
  `undefined`、除外後に偶数個で .5 が出ること

`algorithm.test.ts` は既存のまま全て通ること（リファクタで挙動が変わっていない
ことの確認）。

## 非対象

- 一般ユーザー（非開発モード）への表示
- 平均値・最大値・分散などの併記
- アルゴリズム側の中央値定義の変更
