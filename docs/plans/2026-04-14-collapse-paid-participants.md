# 支払済み参加者の折りたたみ機能

## 背景

参加者管理ページで、支払済みの参加者が多くなるとリストが長くなり、未払いの参加者を確認しづらい。
支払済み参加者を折りたたんで、未払い参加者を優先表示できるようにする。

## 設計

### UIレイアウト

```
参加者一覧 (22人)

┌─ [未払い参加者カード] ─┐  ← 常に表示
│ つっきー  ✓支払  名簿  │
│ マツオ    ✓支払  名簿  │
└─────────────────────────┘

┌─ 支払済み (20人) ▼ ────┐  ← タップで折りたたみ/展開
│ 美玖    ✓支払  ✓名簿   │
│ ほそや  ✓支払  ✓名簿   │
│ ...                     │
└─────────────────────────┘
```

### 仕様

1. 参加者リストを「未払い」と「支払済み」の2グループに分離
2. 未払い参加者は常に表示
3. 支払済みセクションにはヘッダーバーを配置（人数表示 + 折りたたみトグル）
4. デフォルト状態: **折りたたみ（非表示）** — 未払い参加者に注目させるため
5. 折りたたみ状態は `useState` で管理（ページ遷移でリセット）

### トグルボタンデザイン

- テキスト: `支払済み (N人)`
- アイコン: ChevronDown（折りたたみ時） / ChevronUp（展開時）
- スタイル: セマンティックグリーン背景（支払済みを示す）
- タッチターゲット: 44px以上確保

### 対象コンポーネント

- `src/pages/PlayerSelect.tsx` の `renderPlayerList()` 関数を修正

### 変更点

- `sortedPlayers` を `unpaidPlayers` と `paidPlayers` に分割
- 未払いグループを先に表示
- 支払済みグループにトグル付きヘッダーを追加
- lucide-react の `ChevronDown` / `ChevronUp` を使用
