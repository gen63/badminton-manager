# タスク完了済み参加者の折りたたみ機能

## 背景

参加者管理ページで、支払・名簿の両方が完了した参加者が多くなるとリストが長くなり、
未完了の参加者を確認しづらい。タスク完了済み参加者を折りたたんで、未完了者を優先表示する。

## 設計

### UIレイアウト

```
参加者一覧 (22人)

┌─ [未完了の参加者カード] ┐  ← 常に表示
│ つっきー  ✓支払  名簿   │  （支払 or 名簿が未完了）
│ マツオ    ✓支払  名簿   │
└─────────────────────────┘

┌─ 完了済み (20人) ▼ ────┐  ← タップで折りたたみ/展開
│ 美玖    ✓支払  ✓名簿   │  （支払 AND 名簿が両方完了）
│ ほそや  ✓支払  ✓名簿   │
│ ...                     │
└─────────────────────────┘
```

### 仕様

1. 参加者リストを「未完了」と「完了済み」の2グループに分離
2. 完了条件: `operationStatus.payment === true` AND `operationStatus.roster === true`
3. 未完了参加者は常に表示
4. 完了済みセクションにはヘッダーバーを配置（人数表示 + 折りたたみトグル）
5. デフォルト状態: **折りたたみ（非表示）** — 未完了者に注目させるため
6. 折りたたみ状態は `useState` で管理（ページ遷移でリセット）

### トグルボタンデザイン

- テキスト: `完了済み (N人)`
- アイコン: ChevronDown（折りたたみ時） / ChevronUp（展開時）
- スタイル: セマンティックグリーン背景（完了を示す）
- タッチターゲット: 44px以上確保

### 対象コンポーネント

- `src/pages/PlayerSelect.tsx` の `renderPlayerList()` 関数を修正

### 変更点

- `sortedPlayers` を `incompletePlayers` と `completePlayers` に分割
- 未完了グループを先に表示
- 完了済みグループにトグル付きヘッダーを追加
- lucide-react の `ChevronDown` / `ChevronUp` を使用
