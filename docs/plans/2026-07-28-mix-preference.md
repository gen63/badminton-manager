# 少数派性別が少ないとき MIX（2-2）の試合を増やす + ペア重複ペナルティ上限の調整

2026-07-28

## 背景

`2026-07-28-minority-gender-fairness.md` で少数派が**ちょうど1人**のケースは解消したが、
**2人以上でも不利が残っていた**（男12女2 で −0.8試合）。

3-1 を許容して出場機会を作るのではなく、**MIX（2-2）の試合の割合を増やす**方向で
解決したい、という方針。

## 原因

`getGenderPenalty` の優先順位が「同性 4-0 = 0（最優先）> MIX 2-2 = 0.5 > 3-1 = 3.0」
だったため、**少数派2人を同じコートに集めて 2-2 を作る組み合わせが、多数派だけの
4-0 より 0.5 試合分不利**になっていた。少数派が揃って出る機会が抑制されていた。

## 変更

### 1. 少数派が少ないセッションでは MIX を優遇する

- `isMinorityGenderScarce` / `getScarceMinorityGender` を追加。判定は
  `shouldAllowUnbalancedGender` と同じ「少数派が全体の 30% 未満」を流用
- 該当セッションでは `GENDER_MIX_PENALTY` を 0 にする（`preferGenderMix` フラグ）
- 男女が拮抗したセッション（30%以上）では**従来どおり同性 4-0 を優先**

### 2. `repairLoneMinorityPairs`（配置後の修復）

MIX ペナルティを外すだけでは、少数派が別々のコートに1人ずつ散って 3-1 が2つできる
ケースが残る。そこで各ラウンドの選出後に、**少数派がちょうど1人ずつの2コートがあれば、
多数派1人と少数派1人を入れ替えて「2-2 + 4-0」にする**修復を入れる。

出場メンバー自体は変えない（誰がどのコートに入るかだけを変える）ため、試合数の公平性に
影響しない。ガードは3つ:

- 直近6試合と**完全に同じ4人**になる入れ替えは避ける
  （`hasSimilarRecentMatch` の「3人以上重複で無効」をここで使うと、少数派の母数が
  小さいセッションではほぼ全ての入れ替えが弾かれて修復が1件も成立しなかった）
- `hasIsolatedExtreme`（既存）
- **入れ替え後の実力差（`getSkillGapPenalty`）が悪化するなら拒否**

3つ目は重要。当初これが無く、コート間で実力帯をまたぐ入れ替えが通ってしまい、
少数派3人のケースで「上位3×下位3 の同居」が 7.7% → 8.9% に悪化していた。

### 3. `PAIR_REPEAT_PENALTY_CAP` を 0.3 → 0.2

`2026-07-28-pair-diversity.md` のレビューで、21人3コートの実力分離が 2.3% → 2.7% と
わずかに悪化していた（80シードでの標準誤差 0.24pt に対し 1.6 SE 相当で、ノイズと
断定できない）。0.3 / 0.2 / 0.15 / 0.1 を比較した結果:

| cap | 21人3コート 上位3×下位3 | 近い相手との未共演率 | 18人3コート |
| --- | --- | --- | --- |
| 0.3 | 2.7% | 31% | 4.8% |
| **0.2（採用）** | **2.1%** | **31%** | **4.6%** |
| 0.15 | 2.2% | 33% | 4.6% |
| 0.1 | 2.6% | 33% | 4.6% |

0.2 だけが実力分離と多様性を両立する（0.15 / 0.1 は両方悪化）。

## 効果（18人3コート・40シード平均。少数派は実力帯に散らばる配置）

| 少数派 | 指標 | 変更前 | 変更後 |
| --- | --- | --- | --- |
| 2人 | 3-1 の割合 | 29.0% | **23.3%** |
| | 2-2 の割合 | 6.9% | **9.5%** |
| | 上位3×下位3 | 7.0% | **6.5%** |
| 3人 | 3-1 の割合 | 30.8% | **24.0%** |
| | 2-2 の割合 | 16.5% | **20.3%** |
| | 上位3×下位3 | 7.7% | **7.4%** |
| 6人・9人（30%以上） | 全指標 | — | 変化なし（閾値どおり） |

性別なしのセッション（80シード）も改善: 18人3コート 4.8% → 4.6%、21人3コート
2.7% → 2.1%。多様性（実力が近い相手との未共演率）は 31% を維持。

## 計測上の注意

**少数派をどの実力帯に置くかで結果が変わる。** 少数派を最も弱いプレイヤーに固定した
配置（`gender.ts`）では試合数差が改善して見えるが、実力帯に散らばる現実的な配置
（`gbench.ts`）では試合数差は横ばい（少数派2人で 0.47 → 0.58、3人で 0.42 → 0.32）。
本 plan の効果は**「3-1 を減らして 2-2 を増やす」ことであり、試合数差の改善ではない**。

また、性別が未設定のプレイヤーでは `preferGenderMix` も修復も一切動かないため、
性別なしのハーネス（`focus.ts`）ではこの変更の影響を検証できない。

## テスト

- 少数派が少ないセッション（30%未満）では MIX（2-2）が同性（4-0）より優先される
- 男女が拮抗したセッション（30%以上）では従来どおり同性が優先される

## 非対象

- 少数派2人の試合数差（0.5試合前後）。2-2 を作れる構成なので現行の優先度設計どおり
- 2コート同時配置（`assign2CourtsHolistic`）への修復の適用。3コート以上の経路のみ
