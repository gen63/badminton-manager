# スコア入力バリデーションの緩和（同点禁止のみに）

日付: 2026-07-14
ブランチ: `claude/settings-screen-cleanup-65f77p`

## 背景

従来の `validateScore`（ScoreInputPage.tsx）は「15 点先取・デュースは
2 点差・21 点打ち切り」を強制していたが、以下の問題があった:

- **2 点差ルールが誤り**: 実運用では 20-21 のような 1 点差終了もあり得るのに
  「デュース後は 2 点差」で弾いていた。
- 一方で 30-10 のようなルール上ありえないスコアは素通りしており、
  強制が中途半端だった。
- 勝者が目標点数に到達しているかのチェックもなく、そもそも厳密な
  強制になっていなかった。

## 方針

点数ルールの強制はやめ、**バリデーションは「同点禁止」のみ**とする。
（同点だと勝敗が決まらず winner が決定できないため、これだけは残す）

### 変更点（`src/pages/ScoreInputPage.tsx`）

- `validateScore` を同点チェックのみに簡素化
- `getMaxScore` / `maxScore` を削除（デュース上限の概念ごと撤廃）
- `targetScore`（= config の 15）は点数グリッドの ±2 ハイライト表示にのみ
  使い続ける

### 変更しないもの

- 点数ボタンの範囲（0〜30 の固定グリッド）
- 勝者判定（点数の大きい方）、保存処理（`updateMatchScore`）
- `SessionConfig.targetScore`（15 固定のまま）

## 受け入れ確認

- `npm run build` / `npm run lint` / `npm run test:run` がすべて通ること
- 同点入力のみエラーになり、20-21・30-10・11-7 等はすべて記録できること
