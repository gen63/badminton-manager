# 試合履歴カードの名前見切れ解消（チームを上下2段に）

**日付**: 2026-08-12
**ステータス**: 確定
**ブランチ**: `claude/match-history-name-overflow-vk0v24`

---

## Context

試合履歴画面のカードで、チーム名が `truncate`（1行・末尾 `…`）されており、
スマホ幅では大半の試合で名前が見切れていた。

```
30  なべ(みな) こば   VS  タカセアヤカ …
```

原因はレイアウトの構造そのもの。カード内で名前に使える幅は

- 375px 端末 → カード内幅 約231px
- そこから VS バッジ + 左右の gap を引くと **1チームあたり 約96px（日本語 約6.8文字）**

しかダブルスのペア2人分に割り当てられない。名前を折り返しても、この幅では
名前の途中で改行されてしまい、読みやすくならない（実機幅で検証済み）。

## 確定仕様

**左右並び（横）をやめて、チームを上下2段（縦）に並べる。** 各段がカード幅を
まるごと使えるため、ほとんどの試合で名前を省略せずに表示できる。

| 項目 | 仕様 |
|---|---|
| 上段 | 勝者チーム（太字 `text-foreground`）※「勝者を先に出す」既存仕様は不変 |
| 下段 | 敗者チーム（淡色 `text-muted-foreground`）。行頭に `VS` バッジを置いて対戦であることを示す |
| 折り返し | 名前1人ずつを flex アイテムにし、まず**名前の区切り**で改行。1人の名前だけで1行に収まらない場合のみ `break-words` で名前内を折り返す |
| 省略 | `truncate` は廃止（`…` での見切れは発生しない） |
| 時刻・スコア行 | 変更なし（`flex-wrap` だけ追加して極端に狭い端末でも溢れないようにする） |
| 絞り込みメンバーの強調 | 変更なし（indigo 太字。`2026-07-29-history-member-highlight.md`） |
| 未入力カード / 短時間警告 / 編集・削除ボタン | 変更なし |

カード高さは名前が1行に収まる場合で **+1行（約17px）**。従来は見切れていた
名前が読めるようになるトレードオフとして許容する。

## 変更対象ファイル

`src/pages/HistoryPage.tsx` のみ（`TeamNames` と `MatchCard` の名前表示部）。
ロジック・データ構造・他画面への影響はなし。

## 検証

- 実コンポーネント（`MatchCard`）を Vite + 実際の Tailwind ビルドで描画し、
  320px / 375px / 430px 幅でスクリーンショット確認。
  - 375px: 長い名前の組み合わせ（`タカセアヤカ` + `ゆーた(たっちゃん)`）のみ2行、他は各段1行
  - 320px: 折り返しは常に名前の区切りで発生し、名前の途中では切れない
- `npm run build` / `npm run lint` / `npm run test:run`（648 tests）すべて通過
