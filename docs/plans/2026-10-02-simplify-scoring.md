# ダブルス自動配置ルールの単純化（共通通貨「偏差何点分」）

日付: 2026-10-02 / ブランチ: `claude/simplify-scoring`（基点 7fc3d63 = master）

## 背景

目的関数は改修を重ねて項目・係数が増え（`DEFAULT_WEIGHTS` / `VARIETY_SHAPE` / `STRENGTH_SHAPE` /
`RANK_GAP_SOFT_SHAPE` / `RECENCY_STREAK_SHAPE` ほか）、単位がバラバラで重みの意味が読めない。
すべてのソフト項を **「偏差（登録レートをその日のロースターで偏差値化: 平均50・SD10）何点分の悪さか」** に揃え、
1枚の点数表（`SCORE_TABLE`、`pairing/objective.ts`）に集約する。

## 点数表（コスト = 1コート/1ラウンド当たりの合計点。小さいほど良い）

| 悪さ | 点 |
|---|---|
| コート内の最大−最小（偏差） | 1点につき1点 |
| チーム平均の差（偏差）。= 2チームの偏差合計の差 | 1点につき2点（平均差×2 = 合計差） |
| 3人以上一致（過去の試合と、鮮度で減衰） | 8点 × 鮮度（4人一致は4つの3人組に当たり自然に32点） |
| 2連続 / 3連続 / 4連続以上 | 2 / 10 / 40点 |
| 男女3対1（男女比調整ON） / OFF | 6 / 1点 |
| 男男 vs 女女 | ON 2 / OFF 0.33点 |
| 4-0（少数派が少ないセッションのみ） | 3点（OFF 0.5） |
| 希望ペア（normal）が味方にならない | 5点 |
| 試合数の公平性: 理想の選出より何試合ぶん多い人を出したか | 1試合分につき15点 |

（上は初期案。計測後の最終値は末尾「調整後の表」）

## 項目（6項目）とハード（3つ）

項目: 試合数の公平性 / コート内の最大−最小 / チーム平均の差 / 3人以上一致 / 連続 / 男女バランス / ペア希望（normal）。
ハード: ①公平性の窓（`lateBalanceMode` の比率も維持）②ペア希望「必ず」（strong）③極端な実力差（偏差差が閾値以上。人数に関係なく適用）。

撤去: fairness+waiting（→公平性1項）、skillGap の凸形 / 順位混合、competitive の順位版、variety のペア項・同4人項、
`RECENCY_STREAK_SHAPE` の指数形、mixSplit（→男女バランス）、ハシゴ式を使った強さ補正（ladder=0 だったので実質変化なし）、
順位ベースの順位差ハード（14人以上・2/3）。

## 選び方

- 1コート（連続モード・次の試合の予測）: 窓内の候補から4人の全組み合わせ × チーム分け3通りを全列挙し、
  ハード違反の少ない順 → 点数合計が最小のものを採用（全滅時は違反最小→点数最小）。
- 複数コート一括: 既存の局所探索（最急降下、決定的）を新しい点数で使う。

## 互換

旧エンジン（`useObjectiveEngine: false`）・シングルスは触らない。

## 計測・採否

実メンバー試算（練習1: 19人3C / 練習2: 18人3C、男女比OFF、連続モード、50シード、後半均等 0/60%）と bench で master と比較。
結果と調整後の点数表は計測後に追記する。
