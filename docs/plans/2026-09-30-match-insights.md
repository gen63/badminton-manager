# 履歴画面: 試合ごとの分析表示（開発モード限定）

## 目的
メンバーで絞り込んだ履歴で、各試合が「格上に勝った / 取りこぼした」のどれだったかを、
チーム平均偏差値・予想勝率・判定で一目で読めるようにする。

## 表示条件
開発モード（`showPerformance`）かつ メンバー絞り込み中かつ その試合が勝敗確定済みで
推定に使われた試合（`toRatedMatches` を通った試合）。それ以外は既存表示のまま。

## 計算（src/lib/performanceRating.ts）
- 既存の Bradley-Terry のまま: P(A勝) = sigmoid(mean(θ_A) − mean(θ_B))。θ は `solveStrengths` の解を再利用し、既存結果は不変。
- `PerformanceResult.matchInsights: Map<matchId, {teamADeviation, teamBDeviation, winProbabilityA}>`。チーム平均偏差は θ の平均を既存の偏差値変換（50+10*(θ−mean)/sd、sd≈0 なら 50）に通して四捨五入。
- `judgeMatch(ownWinProbability, won)`: p≥0.65 は勝ち=順当勝ち/負け=取りこぼし、p≤0.35 は勝ち=番狂わせ勝ち/負け=順当負け、間は互角・勝ち/互角・負け。
- 閾値の根拠: 1日分（10〜15試合）の推定は誤差が大きく、60%程度の「やや有利」で負けても不思議ではない。有利/不利と言い切れる 65% / 35% を境にした。

## 表示
- 試合カードの中央列と編集/削除アイコン列の間に右寄せの分析列（2列×3行グリッドで中央3行と行揃え）: 上段チームの平均偏差 / 「vs」+下段チームの平均偏差 / 判定チップ+本人側の予想勝率。本人側チームの数字は indigo 太字。
- 成績サマリの期待勝率行の下に判定内訳チップ（0件は非表示、表示中の勝敗確定試合すべてが対象）。
- 判定チップ色: 番狂わせ=emerald / 順当勝ち=blue / 互角=gray / 取りこぼし=orange / 順当負け=淡gray。
