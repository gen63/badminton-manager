# ベル ON 時のテスト再生を「直前のコールの鳴らし直し」にする

- 日付: 2026-09-01
- 対象: `src/lib/matchCallAlert.ts` / `src/pages/MainPage.tsx`

## 背景・課題

ヘッダーのベルを OFF→ON に切り替えると、チャイム・振動に続けて固定のサンプル文言
（`ゆーた さん。1コート付近で試合終了をお待ちください`）を読み上げていた。動作確認
としては機能するが、実運用では別の使われ方が求められていた。

- 体育館は騒がしく、コールを聞き逃す・途中から聞いて自分宛か分からないことがある
- 一時的に音を切っていた端末では、その間のコールが分からないまま
- 「今のもう一回言って」に相当する**手動の音声コール再実行**の導線が無い

## 方針

ベルの ON 切り替えを、**直前のコールの鳴らし直し**として使えるようにする。
新しいボタンやモーダルは足さない（ヘッダーのアイコン列はこれ以上増やせない）。
既存のベル操作の意味を「ON にする ＋ 直前のコールを鳴らす」へ広げるだけにとどめる。

- **直前のコールがある場合**: その文言をそのまま読み上げる
- **直前のコールが無い場合**: 従来どおりサンプル文言でテスト再生する

チャイム・振動は従来どおり鳴らす（読み上げ文言だけが変わる）。

## 実装

### `matchCallAlert.ts` — 直前のコール文言を保持する

モジュールシングルトンの `lastMatchCallSpeech` を追加し、`fireMatchCallAlert(speechText)`
が呼ばれたときに記録する。参照は `getLastMatchCallSpeech()`、クリアは
`clearLastMatchCallSpeech()`（テスト・将来のリセット導線用）。

記録位置は**設定 OFF・hidden の早期 return より前**にする。記録の意味は「直前に
コールが発生した内容」であって「実際に鳴らせた内容」ではない。音を切っていた・
バックグラウンドだったために鳴らなかったコールこそ手動で鳴らし直したいので、
鳴らせなかったコールも記録する必要がある。

`speechText` 未指定の呼び出し（読み上げ無しのコール）では記録を消さない。消すと
「直前のコール」が失われてサンプル文言に戻ってしまうため。

本人向け（`buildNextMatchCallMessage`）・管理者向け（`buildAdminMatchCallMessage`）の
どちらも `fireMatchCallAlert` を通るため、記録先は1つで足りる。管理者端末では
直近に流れた方（＝本当に直前のコール）が鳴る。

### 永続化しない

`sessionStorage` / `localStorage` へは保存しない。リロードすれば `null` に戻り、
サンプル文言でのテスト再生に戻る。有効期限も設けない（鳴らすのは常にユーザーが
ベルを押した瞬間だけで、勝手に古いコールが鳴ることはない。「さっき何て言ってた？」
に答えるのが目的なので、古くなったら鳴らさない、という判断はユーザーに委ねる）。

### `MainPage.tsx` — 読み上げ文言の決定を関数に切り出す

ベルの `onClick` に条件分岐を直接書かず、`buildBellSpeech(courtCount)` に切り出す。
直前のコールがあればそれを返し、無ければ従来どおり `buildNextMatchCallMessage` に
サンプル名（`SPEECH_TEST_NAME` / `SPEECH_TEST_COURT`）を通した文言を返す。
1面運用中にコート番号を出さない判定はサンプル側にのみ効く（鳴らし直しの文言は
作られた時点の判定を既に含んでいるため）。

## テスト

`src/lib/matchCallAlert.test.ts` に `getLastMatchCallSpeech` の describe を追加。

- 一度もコールが起きていなければ `null`
- `fireMatchCallAlert` の `speechText` を記録し、後のコールで上書きする
- 設定 OFF で鳴らせなかったコールも記録する
- hidden 中で鳴らせなかったコールも記録する
- `speechText` なしのコールでは記録を消さない
