# スプレッドシート接続改善

## 日付: 2026-03-10

## 背景
GAS (Google Apps Script) Web App URLの認証切れや接続不安定に対する改善。
現状の問題点:
- POST送信が`no-cors`モードのため、実際に成功したか確認できない
- POST送信にリトライロジックがない（GETのメンバー取得にはある）
- GAS URLが期限切れ・無効になった場合のエラーメッセージが不十分
- 設定画面でURLが有効か事前確認する手段がない

## 改善内容

### 1. 接続テスト関数の追加
- `testGasConnection(url)` - GAS URLにGETリクエストを送り接続確認
- GAS URLが有効か、レスポンスがJSON形式か確認
- 期限切れURLの場合はHTMLが返るため、それを検知してメッセージ表示

### 2. POST送信のリトライロジック
- タイムアウト・ネットワークエラー時に最大2回リトライ
- リトライ間隔: 1秒
- メンバー取得と同様の`retryable`パターンを採用

### 3. エラーメッセージの改善
- GAS URLの期限切れ検知 → 再デプロイを促すメッセージ
- ネットワークオフライン → オフライン状態を明示
- タイムアウト → リトライ中のフィードバック

### 4. 設定画面に接続テストボタン追加
- GAS URLの横に「テスト」ボタン
- テスト結果を表示（成功/失敗 + 詳細メッセージ）

## 対象ファイル
- `src/lib/sheetsApi.ts` - 接続テスト関数、リトライロジック
- `src/lib/sheetsMembers.ts` - エラーメッセージ改善
- `src/pages/SettingsPage.tsx` - 接続テストUI
