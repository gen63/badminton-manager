# 会計画面ブラッシュアップ: シャトル使用可能数 & 免除同期

## 概要
会計画面に2つの改善を実施:
1. 参加費から算出した「シャトル使用可能数」を表示
2. PaymentModalで免除入力した際に会計画面の免除人数欄へ自動反映

## 変更1: シャトル使用可能数の表示

**計算式:**
```
shuttleUsableCount = floor((収入合計 - 体育館代 + その他) / シャトル単価)
```

- 収入合計 = 支払い済み実金額 + 未入力分の推定金額（hybridIncome.total）
- シャトル使用数セクション内に参考値として表示

## 変更2: 免除人数の自動同期

**問題:** PaymentModalで「免除（¥0）」を選択しても、入力タブの免除カウンターが更新されない

**修正:** useEffectでplayersの支払いデータを監視し、免除人数を自動同期
- 免除数は双方向同期（実データに完全一致）
- 男女数は上方向のみ自動調整（手動設定を尊重）
- 無限ループ防止のためdeps配列を制限
