# 少数派性別の試合数差の縮小 + 2コート配置への MIX 修復の適用

2026-07-29

## 背景

`2026-07-28-mix-preference.md` までの対応で 3-1 の試合は減ったが、**試合数の差そのものは
残っていた**。また MIX 修復（`repairLoneMinorityPairs`）は3コート以上の経路にしか
入っていなかった。

## 原因

### 1. ラウンド単位では 2-2 が作れないケース

`isGenderPairImpossible`（3-1 ペナルティの無効化）は**セッション全体で少数派が
ちょうど1人**のときだけ true になる。少数派が2人以上でも、**そのラウンドで片方が既に
別コートに使われていれば、残りの候補では 2-2 が作れない**。それでも 3試合分の
`GENDER_UNBALANCED_PENALTY` が丸ごと掛かるため、残った1人は待たされる。

### 2. `tryFixRecentMatch` が 2-2 を壊していた（2コート経路）

`assign2CourtsHolistic` は少数派2人以上を同じコートにまとめる処理を既に持っているが、
その後段の `tryFixRecentMatch`（直近試合の重複を解消するコート間スワップ）は性別を
見ないため、まとめた 2-2 をまた 3-1 × 2 に散らしてしまう。実測で
**12人2コート・少数派2人のとき 208 回中 28 回（13.5%）**が散らされていた。

## 変更

### 改善1: ラウンド単位の判定を追加

- そのラウンドでまだ使われていない候補（`normalCandidates` から `usedPlayers` を除いた
  もの）に少数派が1人しかいない場合を `roundGenderPairImpossible` として判定
- このとき 3-1 ペナルティを**完全無効化ではなく 0.35 倍に弱める**
  （`GENDER_UNBALANCED_PENALTY_ROUND_SCALE`）

完全無効化にしなかったのは、実測で 3-1 の割合が増えたため。0 / 0.2 / 0.35 / 0.5 / 1.0 を
振って、試合数差の縮小と 3-1 の据え置きが両立する 0.35 を採用した。

セッション全体で少数派が1人の場合（`isGenderPairImpossible`）は従来どおり完全無効化。

### 改善2: 2コート配置にも MIX 修復を適用

`assign2CourtsHolistic` にも `repairLoneMinorityPairs` 相当を適用する。`tryFixRecentMatch`
の**後**に実行し、散らされた 2-2 を復元する。3コート経路と同じく、実力差
（`getSkillGapPenalty`）が悪化する入れ替えは拒否する。

  設定されていないプレイヤーではこのロジックは一切動かない
- 配置時間はむしろ改善（20人4コート60試合の合計 34ms → 26ms）

## 正直な評価

- **目標（試合数差 0.2以内）は少数派3人では達成、少数派2人では未達**（0.48）。
  ベースライン比で 27% の縮小に留まる
- 少数派2人・3コートで 3-1 が +0.6pt、実力分離が +0.4pt 動いている。100シードでの
  標準誤差はそれぞれ 0.61pt / 0.38pt なので**約1SE ＝ ノイズと区別できない**が、
  200シードでの独立測定でも同じ向きに +0.3pt 動いており、わずかな悪化の可能性は残る。
  試合数差の改善（0.66 → 0.48）の方が効果量として大きいため採用した
- 少数派が30%以上でも `roundGenderPairImpossible` は発火しうるため、16人少数派6の
  2コートで数値がわずかに動く（3-1 が 39.1% → 38.7%）。「30%以上は完全に不変」では
  ない。ただし向きは改善側

## テスト

- ラウンド単位の判定: 先のコートで少数派の1人が使われた後、残った1人が自分の実力帯の
  中で拾われることを確認
- 2コート修復: `tryFixRecentMatch` が散らした 2-2 を復元すること / 復元すると直近重複や
  実力差の制約に反する場合は散らしたままにすること

## 非対象

- 少数派2人での残り 0.48試合の差。さらに縮めるには 3-1 の増加か実力分離の悪化を
  受け入れる必要がある
